# Vishleshan AI v2 — Phase 6A Ground-Truth Evaluation Foundation
## Dataset ID: `VISHLESHAN-EVAL-v1`

> [!IMPORTANT]
> **Phase 6A Foundation Notice**:
> Phase 6A establishes the evaluation-data foundation, schemas, provenance policy, validation rules, deterministic SHA-256 hashing, and loading infrastructure. It does NOT constitute research validation.
> No fake companies or fake real-world ground-truth claims have been created to populate these files.

### Distinction of Dataset Categories

1. **Evaluation Schema & Framework**: Defined Pydantic models ([evaluation_dataset.py](file:///c:/Users/arpan/Desktop/VISHLESHAN%20AI/backend/app/schemas/evaluation_dataset.py)) and loader ([dataset_loader.py](file:///c:/Users/arpan/Desktop/VISHLESHAN%20AI/backend/app/evaluation/dataset_loader.py)).
2. **Real Labeled Evaluation Dataset**: Verified real-world ground-truth claims annotated according to [ANNOTATION_GUIDELINES.md](file:///c:/Users/arpan/Desktop/VISHLESHAN%20AI/backend/data/evaluation/ANNOTATION_GUIDELINES.md).
3. **Synthetic / Unit-Test Examples**: Marked explicitly with `is_synthetic: true`. Used strictly for automated unit testing (`backend/tests/test_evaluation_dataset.py`) and excluded from real-world evaluation statistics.
4. **Model Predictions**: Predictions generated by Trust Engine or ML models. **LLM/model predictions must NEVER become ground truth automatically.**

---

### Trust Engine Behavioral Evaluation (`trust_eval.json`)

`trust_eval.json` evaluates deterministic **Trust Engine behavioral scenarios**, NOT subjective human "true company Trust Scores."
- Evaluates expected identity-dimension behavior given verified identity evidence.
- Evaluates `UNABLE_TO_VERIFY` status assignment given missing public evidence.
- Evaluates conflict and confidence level behaviors given contradictory evidence.
- Evaluates scoring reproducibility and determinism.

---

### Recruitment Risk Evaluation (`recruitment_eval.json`)

References the frozen Phase 5A EMSCAD dataset (`backend/data/fake_job_postings.csv`, SHA-256 `54e7f339cf0627b0b2e88102ad0db63c1935aa0f317eeae41ae645ee6e379dd8`) and frozen model artifact (`recruitment_scam_v1.joblib`). The EMSCAD dataset is not duplicated inside this directory.

### Deterministic Dataset Hashing

The loader calculates a canonical SHA-256 hash over all evaluation dataset records to guarantee versioning and reproducibility.
